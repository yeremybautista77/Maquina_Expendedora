# Documentación del proyecto terminado

Carpeta reservada para la **entrega final**. Hoy está vacía a propósito: aquí solo se
coloca material definitivo, no borradores ni fotos de avance.

## Qué se colocará aquí

| Documento | Contenido previsto |
| :--- | :--- |
| Memoria del proyecto | Objetivos, alcance, arquitectura, presupuesto y conclusiones |
| Manual de usuario | Encendido, compra, reembolso, carga de producto y modo administración |
| Manual de mantenimiento | Cambio de motores, limpieza de espirales, ajuste del monedero |
| Registro de pruebas | Resultados con producto real en los seis canales y con monedas |
| Ficha técnica | Consumo, dimensiones, capacidad por canal, tolerancias |
| Material de presentación | Póster, diapositivas y fotografías finales |

## Cuándo se considera terminado

La entrega se traslada aquí cuando se cumplan los criterios de
`../Firmware/ESTADO_DEL_PROYECTO.md` §10 y además:

- [ ] Los seis canales despachan producto real de forma repetible.
- [ ] El monedero acepta y clasifica las cuatro denominaciones.
- [ ] La máquina opera al menos 30 minutos continuos sin reinicios ni *watchdog*.
- [ ] El gabinete está cerrado, con el cableado fijado y sin conductores expuestos.
- [ ] Existen fotografías del equipo terminado y del interior armado.
